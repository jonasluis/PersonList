# Projeto de Cadastro - Integração Java Spring Boot + MySQL + React

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aprofundar conhecimentos na integração entre um backend Java Spring Boot com banco de dados MySQL e um frontend React. O foco principal foi criar uma aplicação de cadastro que demonstra a comunicação efetiva entre estas tecnologias.

## Estrutura do Projeto

### Backend (Java Spring Boot + MySQL)
- Localizado na pasta `/backend`
- Desenvolvido com Spring Boot
- Integração com banco de dados MySQL
- Implementação de APIs RESTful

### Frontend (React)
- Localizado na pasta `/frontend`
- Desenvolvido com React
- Interface moderna e responsiva
- Consumo de APIs do backend

## Tecnologias Utilizadas

### Backend
- Java Spring Boot
- MySQL
- Maven
- Spring Data JPA
- RESTful APIs

### Frontend
- React
- JavaScript/ES6+
- Bootstrap
- Axios para requisições HTTP

## Aprendizados

Este projeto proporcionou experiência prática em:
- Desenvolvimento de APIs RESTful com Spring Boot
- Integração com banco de dados MySQL
- Desenvolvimento de interfaces com React
- Comunicação entre frontend e backend
- Gerenciamento de estado no frontend
- Boas práticas de desenvolvimento
