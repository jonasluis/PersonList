# Frontend - React

## Sobre o Projeto

Esta pasta contém o frontend da aplicação desenvolvido com React. O projeto foi estruturado para fornecer uma interface moderna e responsiva para interação com o backend Java Spring Boot.

## Estrutura de Pastas

```
src/
  ├── layout/     # Componentes de layout
  ├── pages/      # Páginas da aplicação
  ├── users/      # Componentes relacionados a usuários
  ├── App.js      # Componente principal
  └── index.js    # Ponto de entrada da aplicação
```

## Tecnologias Utilizadas

- React
- JavaScript/ES6+
- Bootstrap
- Axios para requisições HTTP

## Scripts Disponíveis

### `npm start`

Inicia o servidor de desenvolvimento.
Abra [http://localhost:3000](http://localhost:3000) para visualizar no navegador.



## Funcionalidades

- Formulários de cadastro
- Listagem de dados
- Integração com APIs do backend

## Desenvolvimento

1. Execute `npm install` para instalar as dependências
2. Configure a URL base da API no arquivo de configuração
3. Execute `npm start` para iniciar o servidor de desenvolvimento
